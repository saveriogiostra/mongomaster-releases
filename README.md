# MongoMaster releases

Installers of MongoMaster, a desktop manager for MongoDB, for Windows.

Download the latest version from [Releases](https://github.com/saveriogiostra/mongomaster-releases/releases/latest):

`MongoMaster_<version>_x64-setup.exe` installs for the current user, without administrator rights. (Versions up to
0.1.1 also came as an MSI package; install only the setup program, so that MongoMaster is installed once.)

Installed copies find new versions here by themselves and ask before installing them; every update is signed and
checked before it is installed.

This repository holds releases only, not the source code.
